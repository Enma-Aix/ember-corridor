# MOV-003 八方向闪避

## 范围

- 玩家按 dodge Action 沿当前输入方向闪避。
- 无方向输入时沿当前左右朝向闪避。
- 闪避方向有水平分量时更新左右朝向；纯纵深闪避保持朝向。
- CharacterBody2D 继续负责 WorldStatic 墙体碰撞。
- PlayerBody 只检测 WorldStatic，因此闪避不会被后续 EnemyBody 软碰撞阻挡。
- 不实现受击、伤害、Hitbox/Hurtbox 或通用战斗状态机。

## 固定 tick 规则

- 总时长：24 tick。
- 位移阶段：第 1 至 10 tick。
- 无敌区间：第 4 至 13 tick，包含首尾。
- 冷却：动作结束后 45 tick。
- 距离：70.4 px，即 32 px 地面碰撞体宽度的 2.2 倍。
- 物理与动作逻辑：60 tick/s。

## 自动化验证

- 24 tick 后动作结束，前 10 tick 累计位移严格为 70.4 px。
- 只有第 4 至 13 tick 返回无敌状态。
- 八方向输入归一化，超范围输入钳制，无输入使用当前朝向。
- 无效朝向不会启动零输入闪避。
- 冷却开始值、倒数第 1 tick 和结束边界准确。
- 真实 movement_sandbox 场景中向 WorldStatic 墙体闪避不会穿墙。
- Linux 与 Windows 原生 Godot 测试，以及 Windows 导出 EXE 启动。

## 人工验收

1. 使用 Godot 4.7.1 Debug 构建启动主场景。
2. 使用 WASD 加 L、左摇杆加 XInput B 分别测试八个方向。
3. 无方向输入时闪避，确认沿当前左右朝向移动。
4. 纯 W/S 闪避不改变左右朝向；带 A/D 分量时朝向匹配水平分量。
5. 贴近四面墙体反复闪避，确认不会穿过 WorldStatic。
6. 观察调试面板：tick 1–24、无敌 4–13、冷却 45–0。
7. 冷却期间连续按闪避，确认不会重启或产生额外位移。

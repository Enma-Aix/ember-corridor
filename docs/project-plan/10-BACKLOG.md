# 可执行开发任务清单

## 1. 使用方法

- 只领取依赖项已完成的任务。
- 每个任务对应独立分支和合并请求。
- S 约 0.5 至 1 天，M 约 2 至 4 天，L 约 1 至 2 周。
- 估算包含实现、自动化测试、人工验收和文档更新。
- 验收条件是最低标准，不得用“能运行”替代。

## 7. Definition of Done

任何任务关闭前必须：

- 实现范围与任务描述一致。
- 相关自动化测试通过。
- 对应人工验收完成并记录。
- 无新增错误或持续警告。
- Debug 工具可观察关键状态。
- 文档与数据字段同步更新。
- 新资源登记来源和许可证。
- 未引入无关重构、网络功能或范围外系统。

# 独立审查提示词

请作为独立审查者检查当前实现，不直接扩大功能范围。

依据：

- README-HANDOFF.md。
- 07-TECHNICAL-ARCHITECTURE.md。
- 当前里程碑退出条件。
- 10-BACKLOG.md 的任务验收。
- 11-ACCEPTANCE-TEST-PLAN.md。
- AGENTS.md。

审查顺序：

1. 确认实现对应的 Backlog ID 和依赖。
2. 运行数据校验、自动化测试和 Windows Debug 导出。
3. 检查状态机、事件生命周期、存档和随机 seed。
4. 检查是否引入网络、范围外系统或第三方依赖。
5. 检查是否存在来源不明、疑似提取或未登记素材。
6. 对照验收用例做最短人工复现。
7. 按 P0 至 P3 报告问题。

每个发现必须给出：

- 严重度。
- 证据。
- 复现步骤。
- 受影响模块。
- 最小修复方向。

不要仅报告代码风格偏好。若没有发现问题，明确说明执行过哪些检查以及仍未覆盖的风险。

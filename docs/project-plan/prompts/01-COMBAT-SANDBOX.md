# 战斗沙盒实现提示词

前提：M0 已全部通过。本轮实现 M1 战斗沙盒，不制作正式地下城。

阅读：

- 03-COMBAT-DESIGN.md
- 04-CLASS-AND-SKILLS.md 中刃契者部分
- 07-TECHNICAL-ARCHITECTURE.md
- 10-BACKLOG.md 的 M1
- AGENTS.md

执行顺序：

1. MOV-001 至 MOV-003。
2. CMB-001 至 CMB-007。
3. CMB-008 至 CMB-010。
4. DBG-001。
5. AI-001 至 AI-004。
6. RM-001 至 RM-003。

必须使用灰盒原创资源。每完成一个可独立验收的 Backlog ID 就运行测试，不要把全部实现堆进一个巨大变更。

重点要求：

- 物理和战斗为 60 tick。
- 视觉高度与地面坐标分离。
- 命中结算不依赖 VFX、动画或 UI。
- AttackDefinition 驱动帧数据。
- 输入缓冲和取消窗口有边界测试。
- 训练假人显示当前状态、Hitbox、DPS 和连击。
- 房间反复进入退出不残留信号和节点。

本轮不做：

- 其余七个技能。
- 装备、掉落、等级、正式存档。
- 正式美术、音乐和首领。

并行设计说明：

- UX-001 可在本轮开始执行。
- CMB-010 与 DBG-001 稳定后，使用真实战斗沙盒截图执行 UX-002。
- 低保真 HUD 只验证信息层级、遮挡、输入提示和焦点流程，不在本轮固化正式视觉。

完成条件以 03-COMBAT-DESIGN.md 第 16 节为准。

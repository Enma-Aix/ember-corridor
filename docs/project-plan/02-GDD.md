# 游戏设计文档

## 1. 核心循环

1. 在灰港查看任务、调整技能和装备。
2. 选择主线地下城与难度。
3. 进入由 5 至 9 个房间组成的固定关卡。
4. 清理战斗房、处理机关、选择短期增益或恢复。
5. 击败精英与首领。
6. 获得经验、金币、材料、装备和首领徽记。
7. 返回灰港，升级技能、制作或兑换装备。
8. 解锁下一地下城或用新 Build 重打已有地下城。

## 2. 游戏状态

| 状态 | 可执行操作 | 存档时机 |
| --- | --- | --- |
| 主菜单 | 新游戏、继续、设置、退出 | 设置修改后 |
| 灰港 | 装备、技能、商店、选关 | 所有成长修改后 |
| 地下城 | 战斗、探索、暂停 | 进入房间、获得关键掉落后 |
| 结算 | 奖励、评分、返回 | 结算确认前后 |
| 失败 | 重试本房、返回灰港 | 失败记录后 |

地下城内允许暂停。退出到主菜单后可从最近房间入口恢复，但房间内敌人状态不会逐个保存。

## 3. 移动与空间

游戏使用横向 X 轴和纵深 Y 轴的 2D 战斗平面：

- 左右移动速度高于纵深移动速度约 10%。
- 角色只能面向左或右，纵深移动不改变朝向。
- 跳跃使用视觉高度变量，不直接改变地面坐标。
- 地面投影决定碰撞位置，角色精灵根据视觉高度向上偏移。
- 角色按地面 Y 坐标排序，确保前后遮挡正确。
- 房间边界和门使用地面碰撞，不与视觉高度耦合。

## 4. 战斗操作

默认键盘：

| 行为 | 默认键位 |
| --- | --- |
| 移动 | W、A、S、D |
| 普通攻击 | J |
| 跳跃 | K |
| 闪避 | L |
| 技能 1 至 4 | U、I、O、P |
| 终极技能 | H |
| 交互 | Space |
| 暂停 | Esc |

默认手柄：

- 左摇杆或方向键移动。
- X 普通攻击。
- A 跳跃。
- B 闪避。
- RB 加 X、Y、A、B 释放四个技能。
- RT 加 Y 释放终极技能。
- View 交互，Menu 暂停。

所有战斗操作必须可重绑定，并检测按键冲突。

## 5. 角色资源

### 5.1 基础属性

- 生命值。
- 攻击力。
- 防御力。
- 暴击率。
- 暴击伤害。
- 移动速度。
- 技能冷却倍率。
- 韧性伤害倍率。

不设置蓝量。普通技能只受冷却限制，终极技能通过造成和承受伤害积累能量，避免玩家因资源不足而停止使用技能。

### 5.2 战斗槽位

- 4 个主动技能槽。
- 1 个终极技能槽。
- 1 个核心被动。
- 6 个装备槽。
- 2 个消耗品槽；消耗品使用次数在每次地下城开始时补充，不需要购买。

## 6. 房间类型

| 类型 | 占比 | 规则 |
| --- | ---: | --- |
| 普通战斗 | 45% | 1 至 3 波敌人 |
| 精英战斗 | 15% | 1 个精英加支援敌人 |
| 机关战斗 | 10% | 战斗同时处理地面机关 |
| 事件 | 10% | 对话、短挑战或选择增益 |
| 休整 | 10% | 恢复、调整技能、预览后续路线 |
| 首领 | 10% | 多阶段首领战 |

主线地下城采用手工固定布局。允许一处分支房间，但主线路径必须清晰。

## 7. 难度

### 故事

- 敌人伤害为普通的 70%。
- 首领失败后可从当前阶段重试。
- 可开启自动普通连击和更长预警。

### 普通

- 设计基准。
- 房间失败可从房间入口重试。
- 首领失败从首领房入口重试。

### 困难

- 通关对应区域后解锁。
- 敌人获得新的招式组合，而不仅是提高数值。
- 敌人生命约为普通的 130%，伤害约为 120%。
- 更高评分提供额外徽记，不掉落困难模式独占的核心剧情内容。

## 8. 失败与恢复

- 生命归零后进入失败界面，不展示写实受伤。
- 每个地下城允许不限次数从当前房间入口重试。
- 重试恢复全部生命，但清除终极能量和临时增益。
- 返回灰港保留已拾取的普通材料，不保留该次尚未结算的装备。
- 不使用耐久损失、掉经验或删除存档等惩罚。

## 9. 评分

关卡结算为 S、A、B、C：

- 完成：基础 50 分。
- 时间：最多 20 分。
- 受伤控制：最多 15 分。
- 连段与精英机制：最多 15 分。

评分只影响额外金币、材料和展示性徽章，不阻断剧情进度。

## 10. 城镇功能

灰港采用紧凑菜单式场景，不建设大型可行走 MMO 城镇。

- 回廊门：选关和难度。
- 工坊：制作、强化和定向兑换。
- 训练室：训练假人、帧数据和伤害统计。
- 档案台：教程、敌人图鉴、剧情记录。
- 休息处：存档槽、设置和返回主菜单。

## 11. 教学

教学分散在第一个地下城前四个房间：

1. 移动、朝向与普通攻击。
2. 跳跃、空中攻击和闪避。
3. 技能、冷却和技能取消。
4. 敌方预警、韧性与破防。

教程提示在玩家完成动作后立即消失，重玩时默认不再强制显示。

## 13. 通关后内容

- 困难模式。
- 关卡评分重打。
- 首领挑战模式。
- 完整技能免费重置。
- 图鉴和装备收集。
- 不做无限层数、赛季、每日任务或在线排行。

## 14. 可访问性与舒适性

- 屏幕震动：0%、25%、50%、100%。
- 命中闪光：关闭、减弱、标准。
- 伤害数字：关闭、仅玩家、全部。
- 字幕：默认开启，可调大小。
- 色彩提示同时使用形状和图标，不只依赖颜色。
- 可选自动普通连击：按住普通攻击即可连段。
- 暂停菜单可查看敌人机制提示。

## 1. 项目一句话

《余烬回廊》是一款原创的 2D 横版卷轴动作 RPG。玩家在可上下移动的战斗平面中，以普通攻击、闪避、技能、浮空与连段清理房间，完成 10 至 18 分钟的手工地下城，并通过确定性成长系统解锁职业能力与装备组合。

项目只借鉴经典横版动作 RPG 的品类体验，不使用《地下城与勇士》的名称、角色、职业、剧情、地图、怪物、UI、音频或美术素材。

## 4. 第一条开发主线

Coding 不应直接制作完整游戏。必须按以下顺序建立可验证的纵向切片：

1. 创建 Godot 工程、输入映射、目录和自动化检查。
2. 用灰盒资源完成玩家移动、转向、跳跃和闪避。
3. 完成普通攻击三连段、命中框、受击框、伤害事件和训练假人。
4. 完成一个技能、一个近战敌人和一个可清理房间。
5. 完成房间门禁、波次、掉落、结算和存档。
6. 再扩展为 1 个职业、8 个技能、4 类敌人、1 个首领和 1 个完整地下城。

在“战斗沙盒”验收以前，禁止投入正式关卡、美术批量制作或完整装备系统。

## 5. 首个可玩版本

Vertical Slice 必须包含：

- 职业：刃契者。
- 技能：8 个主动技能，战斗中装备 4 个。
- 地下城：沉降工厂，共 7 个房间。
- 敌人：巡炉傀儡、钩索工、焰芯浮游体、精英监工。
- 首领：炉心看守。
- 系统：城镇入口、地下城、战斗、战利品、装备、升级、存档、设置。
- 时长：新玩家 15 至 25 分钟完成一次切片。
- 性能：目标测试机 1080p 下稳定 60 FPS。

## 6. 交付与版本控制

- 源码、配置和文档进入 Git。
- PNG、PSD、音频、视频和大型二进制资源使用 Git LFS。
- 每个 Backlog ID 使用独立分支。
- 提交信息格式：类型(任务ID): 简短描述。
- 合并前必须通过启动检查、自动化测试和对应任务的人工验收。
- 不允许把来源不明的素材、商用字体或从其他游戏提取的资源加入仓库。

## 7. 当前仍可调整的内容

以下内容是方案默认值，可以在正式美术制作前调整：

- 正式游戏名称。
- 世界观名词和角色名称。
- 美术风格的像素密度与角色比例。
- 三个职业的最终名称。
- 主线文本、配音范围和具体定价。

以下内容若要调整，必须新建架构决策记录并评估所有里程碑：

- 引擎与脚本语言。
- 单机改联机。
- 2D 改 3D。
- Windows 改为多平台同步首发。
- 固定关卡改为程序化生成。

## 8. 完成标准

项目 1.0 只有同时满足以下条件才算完成：

- 从新存档到最终首领可以完整通关，无阻断问题。
- 三个职业均能完成所有主线地下城。
- 键鼠和手柄均可完成所有操作。
- 存档升级、损坏恢复和设置保存通过测试。
- 目标硬件 1080p 战斗场景稳定 60 FPS。
- 所有第三方资源均有清晰的授权记录。
- 不含任何 DNF 原始素材或可造成混淆的名称与视觉设计。

# M1 CMB-008 刃契者普通三连段测试计划

## 目标

CMB-008 使用三个独立 `AttackDefinition` 和通用 `NormalAttackComboModel` 完成横斩、返斩、挑斩。连段核心不依赖场景、动画、VFX、UI 或音频；沙盒表现只能订阅并展示模型结果。

## 数据基线

| 段 | 定义 ID | 启动/有效/收招 | 普攻取消窗 | 特征 |
| --- | --- | ---: | ---: | --- |
| A1 横斩 | `attack.dev.a1_placeholder` | 6/3/11 | 9–20 | 轻击，基础纵深 |
| A2 返斩 | `attack.bladebound.a2_return_slash` | 7/3/13 | 10–23 | 60 px 纵深判定 |
| A3 挑斩 | `attack.bladebound.a3_rising_slash` | 9/4/18 | 无下一段 | 5 tick 命中停顿数据，普通目标浮空 |

A1/A2 的下一段只由各自 Resource 中的 `action.attack` 取消目标开启。A3 不声明该目标，因此不存在隐式 A4。三段末尾另行声明闪避取消窗，但闪避状态整合不属于本任务。

## 自动化验收

1. 三个 Resource 可加载、ID 唯一、时间线和取消窗有效；加入 CMB-009 后 DataRegistry 共索引 11 个顶层定义。
2. 提前输入：A1 action tick 2 记录的输入在 age 7、A1 tick 9 时进入 A2。
3. 窗口内输入：A2 的输入在 tick 10 进入 A3。
4. 窗口末端：A1 tick 20 输入仍进入 A2。
5. 窗口之后：A1 完整结束后的新输入开始全新 A1，而不是 A2。
6. 落空恢复：没有任何命中事件时，A1 或完整 A3 收招仍稳定回到 idle。
7. 非法配置：中间段缺少 `action.attack` 或 ID 重复时拒绝，且不破坏先前有效配置。
8. 左右镜像：A1/A2/A3 的 Hitbox X 偏移均严格取正负镜像，大小来自各自 Resource。
9. 沙盒集成：一次完整三连段对两个目标各命中三次；A1/A2 不浮空，A3 才使普通目标升空；精英保持免疫。
10. 表现：三段 active tick 显示不同攻击轨迹；攻击期间锁定起手朝向，收招后解除。

## 人工验收

1. 连续按 J / XInput X，确认顺序始终为横斩、返斩、挑斩。
2. 快速提前按、在窗口内按、故意晚按，分别确认缓存连段、即时连段和新链 A1。
3. 从目标左右两侧重复，确认轨迹、判定和伤害方向镜像一致。
4. 面向空处完成一次全链，确认落空不会锁死；再命中目标完成一次全链。
5. 确认第二段纵深覆盖明显宽于第一段，第三段才浮空普通目标。
6. 等待 A3 31 tick 完整结束，确认可移动、可转向并从 A1 再次起手。

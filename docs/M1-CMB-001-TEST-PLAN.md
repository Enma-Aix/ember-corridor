# CMB-001 通用有限状态机

## 范围

- 提供不依赖场景、动画、VFX、UI 或音频节点的 `StateMachineModel`。
- 以 StringName 状态 ID 和显式转换表描述合法转换。
- 只有状态机拥有最终转换权；调用方只能请求目标状态。
- 非法转换不改变当前状态，并通过拒绝码、消息和信号返回原因。
- 不在本任务中固化玩家完整状态图，也不接管现有移动、跳跃或闪避。

## API 契约

- 配置必须声明至少一个状态，且初始状态必须存在。
- 每个转换目标必须是已声明状态；终止状态可以拥有空目标列表。
- 状态和目标 ID 不允许为空、外围空白或重复。
- 无效配置是事务性的，不覆盖上一份有效配置与运行时状态。
- 自转换没有隐式特权，只有显式列入转换表才合法。
- 成功转换更新 previous/current、递增计数并发出 `state_changed`。
- 失败请求保留状态与计数，并发出带稳定拒绝码的 `transition_rejected`。
- 查询返回转换列表副本，调用方不能从外部修改内部表。

## 自动化验证

- 有效配置、初始状态、已知状态与多目标查询。
- 连续合法转换的 previous/current、计数和信号载荷。
- 未配置、空目标、未知目标和表中禁止的转换全部被结构化拒绝。
- 空表、未知初始状态、未知目标、重复目标和错误集合类型配置失败。
- 无效重新配置不污染有效状态机。
- 终止状态稳定，不因模拟的 120 个固定 tick 或不同 delta 自动改变。
- reset 恢复初始状态；对象释放后不留下全局监听或场景节点。
- Linux 与 Windows 原生 Godot 测试，以及 Windows 导出 EXE 启动。

## 人工验收

1. 使用 Godot 4.7.1 Debug 构建启动主场景。
2. 确认日志包含 `[StateMachineSandbox] CMB-001 core ready`。
3. 运行测试脚本，确认合法转换、非法转换与终止状态用例全部通过。
4. 确认移动、跳跃和闪避沙盒行为与 MOV-001/002/003 一致。
5. 检查 Release 导出不显示调试面板，状态机核心不依赖表现层。

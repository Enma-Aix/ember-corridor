# MOV-001 地面移动与朝向

## 范围

- 玩家在地面平面进行八方向移动。
- 横向速度为 320 px/s，纵深速度为横向的 90%。
- 只有有效的水平输入改变左右朝向；纯纵深移动和微小摇杆抖动保持朝向。
- 使用 CharacterBody2D 与 WorldStatic 碰撞，不实现跳跃、闪避或战斗。

## 自动化验证

- 横向、纵深和零输入速度。
- 对角输入归一化以及超范围输入钳制。
- 左右朝向、纯纵深输入和阈值内抖动。
- 非正速度、非正纵深比例和大于 1 的比例被拒绝且不污染当前配置。
- Linux 与 Windows 原生 Godot 测试。
- Windows 导出 EXE 启动并确认 MOV-001 沙盒实例化。

## 人工验收

1. 使用 Godot 4.7.1 Debug 构建启动工程。
2. 分别按 W、A、S、D，确认四个方向移动。
3. 同时按两个相邻方向，确认对角移动没有加速。
4. 只按 W/S，确认朝向不改变；按 A/D，确认朝向稳定翻转。
5. 沿四面边界持续移动，确认不能穿过 WorldStatic 墙体。
6. 在 1280×720 下观察调试面板的位置、速度和朝向。

# Ember Corridor 0.1.2 Visual Slice 测试结果

## 已验证

- Godot 4.7.1 Stable 工程导入与主场景无脚本错误启动。
- 15 项 Resource 定义加载与数据校验。
- 88 项自动化测试全部通过，其中新增视觉竖切片启动、运行时角色/敌人美术、中文字体、敌人近身攻击、玩家受伤与结束状态测试。
- 1280×720 同运行时资产布局预检：标题页和战斗 HUD 均无浏览器错误、溢出或缺失中文字体。
- Windows x64 发布导出、PE32+ 架构、嵌入式 PCK、压缩包内容与 SHA-256 校验。

## 环境边界

当前 Linux 构建环境没有可用的图形显示服务，也不能原生执行 Windows 图形程序，因此无法在这里提供真实 Windows Godot 窗口截图或完成 Windows 键盘手感验收。布局预检只用于检查同资产构图，不冒充 Godot 实机截图；最终 Windows 图形验收仍需在 Windows 10/11 上完成。

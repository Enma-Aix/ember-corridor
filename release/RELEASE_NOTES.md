# Ember Corridor 0.1.2 Visual Slice

这是《余烬回廊》旧方向的 Windows x64 可玩视觉竖切片。它用于纠正 0.1.1 把灰盒测试场当成玩家版本的问题；0.1.1 已撤回，不再建议下载。

## 可体验内容

- 标题页与“进入熔炉回廊”开始流程。
- 一张完整的熔炉回廊战斗场景，运行时角色、机械蛛与盾卫美术。
- 两类敌人会追击、起手攻击并造成伤害。
- 玩家与敌人生命条、技能栏、任务计数、胜利/失败与重开流程。
- WASD 移动，K 跳跃，L 闪避，J 三连段，U 破线突。
- 输入缓冲、攻击时间线、命中判定、伤害、韧性、浮空与命中反馈继续保留。

## 明确限制

- 只有一个可玩房间，没有多房间关卡、成长、装备、存档或完整游戏循环。
- 当前角色与敌人动画只覆盖必要战斗状态，VFX、SFX 与音乐尚未完成。
- 运行时美术由此前概念方向延展而来，只批准用于本次纠偏预览，不是最终发行素材。
- 本版本不是经过完整 DNF 品类研究形成的原型，不能作为后续正式方向基准。
- Windows 可执行文件未签名，系统可能显示未知发布者提示。

## 验证范围

- Godot 4.7.1 Stable。
- 静态工程契约与 Resource 数据校验。
- 88 项确定性自动化测试，其中包含视觉竖切启动、运行时美术、敌人攻击与结束状态。
- Linux 沙盒中的主场景启动、导出 PCK 启动与输入/战斗场景集成测试。
- Windows PE32+ x86-64 格式、嵌入式 PCK 与发布包内容检查。

当前执行沙盒不能运行 Windows 图形窗口，因此真实 Windows 画面、键盘手感与实体 XInput 手柄仍需在 Windows 10/11 上验收。

本构建以 GitHub prerelease 形式发布：GitHub Actions 会原生构建、安装并无头启动 Windows 包，但窗口画面与输入手感仍属于用户验收项。
